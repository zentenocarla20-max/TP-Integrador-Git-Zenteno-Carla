Descripción
Trabajo Integrador de Introducción a Git y GitHub para la Gestión de Proyectos Digitales en el NODO Tecnologico.

Objetivo
En el siguiente Proyecto se busca demostrar los conocimientos obtenidos en este curso llamado "Introducción a Git y GitHub para la gestión de Proyectos Digitales" sobre la correcta forma de usar los comandos de Git local y GitHub remotamente.

Estructura del repositorio
La estructura del proyecto se basa en una carpeta inicial con el nombre del alumno, luego un README.MD explicando el proyecto y un ENTREGA.MD registrando el proceso del trabajo. Al finalizar se crearan dos archivos: calculadora_basica.html y style.css con código interno para el desarrollo de una calculadora. TP-Integrador-Git-Zenteno-Carla/ │ ├── README.md ├── ENTREGA.md └── proyecto/calculadora └── calculadora_basica.html └── style.css
